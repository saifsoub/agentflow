# AgentFlow — plain-language README

## What this is
A to-do board for projects, contained in a single web page. You can hand tasks to AI helpers as well as to people.

## Who it's for
Anyone who wants a simple task board and likes the idea of AI helpers picking up some of the work.

## What it does today
- Tracks tasks across five columns: Backlog, To do, In progress, In review, Done.
- Marks priority: Urgent, High, Medium, Low.
- Lets you assign a task to an AI helper instead of a person.
- Shows how many helpers are "online".
- Lets you open a chat with a helper from the board.
- Search with ⌘K (Ctrl+K), move with the arrow keys and open with Enter.
- Groups tasks by who they're assigned to, or by column.

It all runs inside the page. There's no server, and it doesn't connect to the internet, so the helpers and chats are simulated rather than real AI.

## How to run it
Open `index.html` in a modern browser. No install needed.

## Current status and known gaps
- Works as a self-contained demo.
- No real AI helpers are connected.
- Whether your tasks are saved after you close the page: not yet confirmed.
